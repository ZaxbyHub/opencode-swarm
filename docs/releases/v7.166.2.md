## Fix

Closes #2472 (Workstream A, PR 4 of 5): removes hot-path stalls from `tool.execute.after` and the chat-transform prompt-construction path, and makes the plugin runtime lifecycle restart-safe.

### Hot-path stalls removed

- **Repo-graph (REPOGRAPH-1):** `toolAfter` now applies the write-tool filter (plus path/exclusion checks) BEFORE awaiting the startup-scan promise, so read/grep/glob/bash results are no longer withheld for the whole scan (previously up to minutes on a fresh clone or after each release). The startup scan itself gained an overall wall-clock budget (`STARTUP_SCAN_BUDGET_MS`, 30 s, fail-open) and a non-debug "Scan start" announcement.
- **Hive promoter (KNOWLEDGE-1):** the promoter hook now runs only for write-class tools, exits before any git spawn / receipt-ledger replay / hive lock when there are no active promotion candidates, and enforces a 60 s per-directory cadence floor; cohort resolution routes through the existing `ensureCohortIdCached` cache. The one-time legacy curator-summary migration is preserved behind a once-per-directory guard.
- **Absent-file reads (PERF-1):** `readSwarmFileAsync` and the context-budget reader no longer pay 4×10 ms retry sleeps for files that have never existed — a first-miss ENOENT returns immediately. The rename-race retry ladder still fires when there is evidence a retry can help (this process wrote the file within the last 500 ms, or the file was previously observed to exist). The Windows AV (EBUSY/EPERM/EACCES) backoff is unchanged (#1782).
- **Prompt-construction maintenance (obligation 1a):** the doc-index directory scan and the dark-matter git spawn + write moved off the synchronous `system.transform` body into a deferred, per-directory single-flight background task.
- **Named transform handlers (obligation 1b):** all seven anonymous inline handlers in the `messages.transform` and `system.transform` chains are now named, so `safeHook` failure logs identify the failing stage instead of `unknown`.

### Restart-safe lifecycle

- `dispose` now stops the automation manager and both workers, unsubscribes PR event listeners, removes the process `exit` listener, and evicts only this project's pooled provider handles (`evictAndClose(directory)`, never the global `clearPool`).
- Process-exit cleanup is registered exactly once per process (once-guarded dispatcher keyed by instance) with best-effort SIGINT/SIGTERM coverage that restores default behavior.
- `initTelemetry` re-homes the telemetry stream when a different project directory initializes (previously the first directory latched forever); `setOnSubscriptionCreated` returns the previous callback so re-registration can retain and invoke it.

### Other obligations

- **Snapshot parity guard (#1640):** `SESSION_TRANSIENT_FIELDS` — a compile-time exhaustive map requiring every `AgentSessionState` field to be either serialized or carry an explicit transient-field rationale (38 documented transient fields), plus a reverse-direction type guard; enforced by typecheck and a runtime round-trip parity test.
- **Async workspace snapshots (#2247):** hook paths now use `captureWorkspaceSnapshotAsync` (bounded, invariant-3-compliant) with an unchanged-content digest skip; the remaining transitive sync spawns (`changedFilesSinceSnapshot`, phase-participation capture, coder-settlement error-path probe) were converted too.
- **Candidate memoization (#2183):** `normalizeCandidateArtifact` results are memoized by artifact digest in a bounded 512-entry cache (`normalizeCandidateArtifactCached`, `invalidateCandidateArtifactCache`, `candidateArtifactCacheStats`).

### New guardrail tests

- `tests/unit/hooks/tool-after-latency-budget.test.ts` — the fully composed `tool.execute.after` chain on a representative read call must complete within a stated budget (the issue's class-level acceptance criterion).
- `tests/unit/hooks/no-sync-spawn-ratchet.test.ts` — static ratchet against sync git spawns reachable from hook paths.
- `tests/unit/lifecycle/plugin-restart-roundtrip.test.ts` and `tests/unit/lifecycle/multi-project-init-isolation.test.ts` — restart round trip and multi-project isolation.
