# Plan-critic model inheritance parity

## Fixed

- Plan-critic dispatch preflight now validates the same effective model as runtime Task routing, including inherited `critic` models, explicit critic-variant overrides, and named-swarm overrides. This prevents valid critic dispatches from being blocked because preflight checked an unused default model.
- Unresolved-model diagnostics now identify the exact generated critic target and its effective configuration, so named-swarm users are no longer directed to a top-level key that may not control the target.

## Migration

No configuration changes are required.

## Breaking changes

None.

## Known caveats

None.

## Summary
- Wired `placeholder_scan` diff scoping into the Stage A callers: the execute skill (step 5e) and the architect prompt now instruct passing `added_lines` (file path → task-added line numbers from a working-tree `git diff -U0 HEAD`) so only task-added lines drive the placeholder verdict. Fail-closed fallback: omit a file from the map when its added lines are unknown or empty — the tool scans it unfiltered, then cross-check its findings against the changed lines manually. Never pass an empty line array or guess line numbers; either silently suppresses findings.
- Added the smallest-justified-scope rule for `SCOPE_CONFLICT` to the swarm-implement skill (Phase 3): reconcile the intended file list, narrow the conflicting lower-precedence source (stale plan scope via `save_plan` and/or `FILE:` lines) before re-declaring, or split the task — never widen to a plan-inferred superset.
- Added the plan-freeze-after-approval rule to the critic-gate skill (both mirrors, byte-identical), aligned with what the coder dispatch gate actually hashes (`computePlanStructureHash`): status-only changes never invalidate the approval; material structural changes (task add/remove; `id`, `phase`, `description`, `acceptance`, `depends`; `removed_task_ids`) require exactly one re-critic; `fr_refs` changes are material on process grounds even though the hash excludes them; and hashed bookkeeping fields (including `files_touched` reconciliation repairs) trip the gate mechanically — for pure bookkeeping repairs the gate's own `approve_plan_critic` recovery with a truthful audited reason replaces a full re-critic.
- Added docs-attestation integrity to the phase-wrap skill: a docs agent may attest "no further edits needed" only after inspecting the phase's changed files and recording what it checked — not as a mechanical no-op against the dispatch gate. Guidance only; a structured enforcement seam remains future work.
- Corrected the qa-sweep skill's stale claim that `placeholder_scan` "has no baseline concept": the tool has been diff-aware via `added_lines` and keeps `allow_globs` for intentionally retained debt.
- Recorded the issue #1994 post-mortem correction durably in `docs/engineering-invariants.md`: FR-009 is DESCOPE (the runtime 3× idle-poll cap shipped hard-coded via PR #1978, integrating the issue-#1691 investigation branch; commit `b7e12d36` — post-rewrite twin `d82c7172` — had recorded FR-009 deferred, and the schema-configurable multipliers it guarded never existed, so there is no `.refine` target), and the schema-primary + observable-runtime-fallback dual-validation pattern is recorded as PROPOSED, not an established precedent.

## Why
- Issue #1994's post-mortem audit (verdict LOW_TRUST) found the session review fabricated an FR-009 closure precedent and produced 7 recommendations; the corrective PR #2001 was closed unmerged, so none of its dispositions reached `main`.
- S2 (biome `lint --fix` after each coder) and P3 (design-review-before-impl) were reviewed and rejected — see issue #1994 for the reasoning; no action taken.

## Migration
- No migration required. All edits are additive skill/prompt guidance and documentation; no runtime tool behavior changed.

## Caveats
- The added-lines guidance relies on the caller computing line numbers from a real diff; the prescribed fallback (omit the file → unfiltered fail-closed scan → manual cross-check) keeps a wrong or missing map from silently suppressing findings.
