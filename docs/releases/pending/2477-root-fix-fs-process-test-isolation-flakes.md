  - **pkg-audit combined-process hang (#2260):** both `pkg-audit-composer(.adversarial).test.ts` file-scope `mock.module`s of `src/build/discovery` are gone. Their "delegate to the real module" branch was infinite tail recursion — Bun's `mock.module` retroactively patches the original module's export slots, so the captured pre-mock namespace import resolved the overridden export back to the mock itself; because the delegation is a tail call under JSC proper tail calls, it presented as an unkillable process hang (shard rc=124) rather than a test failure. ## Why
- The merge-group CI matrix (Windows × macOS × coverage × integration) surfaces this flake family on cold runners; the historical quarantine response kicked valid PRs out of the queue repeatedly (issues #1782, #1737). The pkg-audit pair alone turned any co-locating shard into a wall-clock timeout that presented as infrastructure failure — the exact "easy to retry away without diagnosing" failure mode #2260 describes.

## Migration
- No production code changed — all fixes are test-infra or CI-gate side. The new Check 7 only fails if a future quarantine entry is added without OWNER/EXPIRY metadata or lets an entry rot past its grace window; existing entries were annotated at introduction.
