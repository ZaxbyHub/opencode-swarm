## Summary

- **First-run activation** (#2493): a fresh `opencode-swarm` install now writes `auto_select_architect: true` into the host config and emits a one-time-per-session advisory when a non-architect swarm agent runs, explaining how to invoke the architect (or dismiss it). The bundled `plan` skill was renamed to `swarm-plan` so it no longer shadows OpenCode's native `/plan` command (#2388), with a CI-side native-command collision guard for future skill slugs.
- **Install is idempotent** (#2437): re-running install against an existing config only rewrites when the swarm-relevant keys actually change (semantic compare, not byte compare). Formatting, unrelated user keys, and user-re-enabled agents are preserved; a timestamped backup (`opencode.swarm-install-backup.json`) is written before any rewrite, `OPENCODE_CONFIG_DIR` is honored via the host config-dir resolver, and an already-correct config is left byte-identical ("no rewrite" path).
- **CLI / command parity** (#1646): pure-alias commands (the 37 dash-form and legacy spellings) no longer duplicate their canonical handler; they dereference through `aliasOf`, so aliases can never drift from the canonical behavior. The CLI (`opencode-swarm run`) now maps handler failures to real exit codes via a structured `CommandFailure` result, prints did-you-mean suggestions and deprecation warnings to stderr, and `/swarm turbo` rejects unknown arguments instead of silently treating them as `on` (the issue's `turbo.ts:248` gap). `/swarm benchmark --ci` exits non-zero when its CI gate fails.
- **Tool-contract honesty**: `save_plan`'s `size` parameter now documents that omitted sizes on revisions keep the existing task size (previously implied a required re-declaration), and `test_runner`'s `timeout_ms` schema now carries its real default instead of describing a default it did not encode.
- **Decision-drift visibility** (#1661 residual): the shared context-decision parser now returns structured decisions with their raw source text, and `/swarm status` surfaces a decision-drift section so stale plan decisions are visible without opening the plan file.
- **Repo hygiene**: the stray `file.txt` artifact at the repo root was deleted.
