# Verify release reviews and trace evidence

Release-bound issue traces schedule native Swarm review for the exact pull request head. Merge admission verifies the native submission receipt against GitHub and blocks stale, incomplete, or altered review evidence. Review lanes return partial coverage when the host budget is exhausted.

Checkpoint freezing also generates a base replay and test inventory. New trace checks verify published acceptance commands, checkpoint receipts, and the squash patch against the reviewed change.
