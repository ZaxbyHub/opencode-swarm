## Unified atomic writes with registered temp grammars; stale residue is now quarantined, never blindly deleted

Before this change, every atomic-write helper invented its own temporary-file naming grammar (~40 distinct shapes across ~100 call sites), and the close-time cleanup sweep only recognized files starting with `.tmp.` — a legacy prefix that no current writer produces. Interrupted writers left `target.tmp.<timestamp>.<random>` residue under `.swarm/` forever, while the sweep itself deleted any `.tmp.*` file unconditionally, including git-tracked or recently-written ones.

**One canonical writer.** `src/utils/atomic-write.ts` now provides the single contained atomic-write helper (`atomicWriteSwarmFile`/`Sync`): `.swarm`-root containment (symlink-rejecting, `validateSwarmPath`-inspired; the Windows-junction limitation is documented in-code), a unique non-predictable registered temp grammar (`<target>.<hex32>.tmp`), bounded payload, fsync-before-rename, bounded Windows rename retry, and exact `finally` cleanup of its own temp. Fourteen duplicated bespoke writers migrated (including the four skill services whose failure path previously leaked temps on every error); specialized writers (fsync'd ledger/identity-verified/lock-scoped stores, and writers outside `.swarm`) stay bespoke with a documented invariant reason in the registry.

**Registered grammars, exact discovery.** All ~17 grammar families — current, canonical, and legacy — are frozen in `SWARM_TEMP_GRAMMARS` with per-producer citations, and a ratchet test fails the build when a new temp constructor appears unclassified. Scanners classify candidates by exact registered grammars only; near-misses (case variants, trailing dots, ADS-style names) match nothing and are preserved.

**Recoverable quarantine instead of blind deletion.** Close now discovers residue via the shared inventory and MOVES verified stale temps (≥30 min old, git-untracked, unlocked, non-symlink, parsed target present) into `.swarm/quarantine/<batch>/` with a manifest recording original path, sha256, bytes, mtime, and owning grammar. Recent, active, tracked, symlink, constant-name, and unmatched candidates are preserved in place and reported. `/swarm config doctor` shows the same read-only inventory and gains `--quarantine-residue` / `--rollback-residue-quarantine`; `/swarm finalize --dry-run` previews it. Rollback is manifest-verified, idempotent, and never overwrites differing content. A bounded `residue_health` telemetry event (counts and grammar ids only — no paths) feeds later reporting.
