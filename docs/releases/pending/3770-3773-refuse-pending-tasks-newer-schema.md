Closes #3770, closes #3773.

- `phase_complete` now REFUSES to complete a phase while any planned task in it is unfinished (status is neither `completed` nor `closed` — the readiness predicate shared with Epic phase-readiness; `blocked` refuses, matching Epic's wave-close semantics). The refusal names every unfinished task ID and returns a structured `update_task_status` recovery. The check runs early (before any state-mutating step, so a refused call leaves `.swarm/` byte-identical and never creates `plan.md`) and again as an always-applicable preflight gate at the commit boundary — Turbo does NOT bypass it (the turbo enable disclosure now says so). It reads the authoritative plan state observationally (ledger peek with file/SQLite authority resolution; the plan.json projection only when no ledger authority exists) and defers to the existing error paths on corrupt/truncated/unreadable authorities. `phase_complete.enabled: false` remains the documented operator bypass of completion enforcement.
- The `phase_complete` core event is now exactly-once (#3770's pinned preserving failure): a normal completion records a durable `phase_completed` ledger event (parity with the close-terminal path; `savePlan` gained `completedPhaseIds`), and the core event is appended through the authority-key dedupe keyed by `(ledger root digest, phase, transition seq)`. Duplicate calls and crash-between-save-and-append retries collapse to one record; a re-rooted plan's new completion gets a distinct identity; concurrent double-calls write one event (the plan lock serializes the transition and the already-complete guard keeps the loser from appending — the dedupe additionally guards the sequential duplicate path).
- `getProjectDb` (and the global-rules + memory sqlite stores) now REFUSE writable open with a typed `schema_newer_than_supported` `ProjectDbError` naming the recorded and supported versions when a database's `schema_migrations` records a newer schema than this client knows (#3773) — schema and rows are preserved, the read-only open stays available for diagnostics, `getGlobalDb` closes its raw handle on the refusal, and the `/swarm close` sqlite archive opens its VACUUM INTO source read-only. Current and supported-older schemas keep opening/migrating exactly as before. Public type surface: `ProjectDbErrorCategory` gains `schema_newer_than_supported` (additive).
