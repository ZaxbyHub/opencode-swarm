- **Test Runner Targets Support**: Implemented the `targets` array in `test_runner` to support framework-native targeting conventions that bypass file mapping. Frameworks like `ctest`, `go-test`, `cargo`, `maven`, `gradle`, `dotnet-test`, and `swift-test` can now receive direct targets (e.g., `-R auto-src-controller-stateManager` for `ctest`, `-run TestFoo` for `go test`). The `test_engineer` prompt has been updated to use `targets` instead of `files` for these frameworks to prevent false `SKIPPED` results.
