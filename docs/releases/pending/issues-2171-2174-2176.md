# Worktree-safe tools and exact native test targeting

- Tools created through the shared swarm wrapper now honor explicit project/worktree roots consistently, including nested tool calls.
- `test_runner` can run one exact Go test/subtest or CTest name without a broad package/build-tree fallback, and `test_engineer` documents the bounded target form.
- FILE scope directives now ignore trailing prose annotations consistently in enforcement and telemetry while preserving legitimate quoted and parenthesized paths.

This fixes state mismatches in linked worktrees, false `SKIPPED` results for native test frameworks, and scope conflicts caused by human-readable FILE annotations.

No migration is required. Existing file-based test scopes and tool-owned `working_directory` contracts remain compatible. Native target mode intentionally rejects coverage, bail, ambiguous target arguments, zero-match results, and paths outside the project root.
