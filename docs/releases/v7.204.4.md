# Verification-surface gates: battery admission proof, recurrence-table generator, cluster preflight, cost/yield ledger, PR-body order check, gate-state parity ratchet

## What

Closes seven verification/process gaps surfaced by the PR #3593 retrospective (#3605) and the local-gate subset gap (#3601), each by an executing check instead of orchestrator discipline: a fail-closed multi-file battery wrapper (`scripts/ci/run-test-battery.ts` — refuses unmatched paths that raw `bun test` batches silently drop, propagates failures, asserts discovered == executed, records a tree receipt); a merge-queue-readiness tree-receipt checker (`scripts/ci/check-battery-tree-receipt.sh` + protocol wiring) that refuses a battery whose recorded tree is not the tree it must validate; a fail-closed Phase 4.2 disposition-table generator (`.opencode/skills/issue-tracer/scripts/generate-recurrence-table.sh` — unmatched joins, digest disagreement, and count drift become refusals); a recorded cluster-preflight artifact required by `trace-check.sh phase 1` (per-candidate claim + open-PR evidence; issue-tracer v3.0.3); a per-lane cost/yield ledger for broad reviews (`.opencode/skills/swarm-pr-review/scripts/cost-yield-ledger.sh` + Phase 9 step + harness-recovery reference; cost and yield are paired per row); a local PR-body section-ORDER gate mirror (`scripts/check-publication-body-order.sh` wired into the publication gate); and a one-directional `PrWorkflowGateStateSchema` → `PrWorkflowGateState` shape-parity ratchet (AST-based; fails closed on unsupported declaration shapes). Also re-anchors three stale prose citations and bumps the issue-tracer (201→202) and swarm-pr-review (1716→1717) progressive-disclosure baselines with justification.

Migration note: the cluster-preflight requirement makes `trace-check.sh phase 1` refuse traces created before issue-tracer v3.0.3 that lack `repro/cluster-preflight.md`; record the preflight artifact (template in `references/phase-0-setup.md`) before re-running phase 1 on such a trace.

## Why

During the PR #3593 cycle a pin battery invoked a wrong-directory path, bun silently ran the remaining files, the recorded pass was vacuous, and CI's virtual-merge run caught it ~40 minutes later; the Phase 4.2 table pipeline fell back silently on unmatched joins and consumed two critic rounds; cluster selection spent ~15 minutes of setup on issues a parallel session had claimed; the local publication gate passed a wrongly-ordered PR body that the remote pr-standards check then failed; and a schema/interface divergence produced 15 CI-invisible TS2339 errors in test files. Each failure mode was enforced only by orchestrator vigilance; each is now a local, fail-closed check (issues #3605, #3601).
