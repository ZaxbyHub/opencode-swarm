# Unify invocation failures, bounded retries, model fallback, and Full-Auto recovery

Issue: #2103 (Guardrail remediation 8/12). Also closes #1964.

## What changed

- **Structured invocation-failure taxonomy** (`src/utils/invocation-failure.ts`): one versioned, channel-separated classifier shared by guardrails and circuits. Provider patterns run only on dispatch-channel signals (a shell printing "Disk quota exceeded" can never look like a provider quota error); `command_not_found` requires structured proof (exit 127, spawn ENOENT, or shell-diagnostic grammar — never a loose mid-prose stdout substring); `ENOSPC`/`EPERM` are operator actions, `EBUSY` gets bounded retry, git conflicts enter repair-then-retry, containment denials are never retried into a bypass.
- **Semantic delegation digest** (`src/hooks/loop-detector.ts`): delegation loop identity now hashes the normalized target role, strict plan-task identity, and a SHA-256 digest of bounded argument values (sorted keys, no raw prompts stored). Five distinct tasks to one role no longer trip the loop detector; a true retry still does. The inaccurate "Session paused" text is gone — the stop is delegation-scoped.
- **Action-local, recoverable circuits** (`src/hooks/guardrails/nontransient-circuit.ts`): a hard stop now blocks the failing action's scope (shell execution for parser/missing-command/sandbox-wrapper; the recording tool for threshold-3 categories) instead of every tool in the invocation. Read/diagnose/rescope/handoff/abort tools are never blocked. Corrected success clears the matching non-immediate circuit; immediate categories stay fail-closed and clear through a new audited recovery transition (`recoverNonTransientCircuit`, telemetry-emitted). Gate-denial streaks now include strict plan-task identity so denials for different tasks to the same role no longer share one streak.
- **Real per-session model fallback** (`src/agents/model-override.ts`): the old mutation of the shared `swarmAgents[role].model` config (cross-session leak, never read by any dispatch path) is removed. A bounded LRU store keyed `(sessionID, swarmId, baseRole)` now feeds a shared resolver that every real per-call-override dispatch path consults (lean runner/reviewer/phase critic, Full-Auto oversight and intercept, auto-review, curator and skill-improver delegates) — the override reaches the actual SDK `model` argument. A successful response for the role resets to primary; exhaustion is explicit. Two boundaries are documented: ordinary OpenCode Task delegation resolves its model from the static agent definition in the host, which the plugin cannot override per-call; and the auto-review engine dispatches from fresh ephemeral sessions that hold no per-(session, role) override entry, so it keeps its own independent fallback chain (the remaining six plugin dispatch paths — lean runner/reviewer/phase critic, oversight, intercept, curator, skill-improver — all honor the store).
- **Proportional Full-Auto risk** (`src/full-auto/policy.ts`): in supervised/assisted modes, a delegation to a registered strictly-read-only role (capability-map verified: every tool in the role's map is a safe analysis tool) may take the lower-risk local route. Strict mode always escalates every delegation regardless of `permission_policy.enabled`. Role labels or "read-only" prose in delegation args never lower risk; unknown and mutation/network/execution-capable roles stay escalated high; containment/destructive/protected gates still run independently.
- **One total deadline around oversight** (`full_auto.oversight.total_timeout_ms`, default 120 000, bounded 10 000–600 000): session creation, prompt, retries, backoff (capped to the remaining budget), parse, and cleanup for a single oversight operation all stop within it — implemented with the shared manual-`AbortController` utility, with an outer race so the caller returns even if the host ignores the abort signal. Timeout is recorded distinctly from rejection (`OVERSIGHT TIMEOUT` reason naming the recovery controls); the escalated action stays denied and the run pauses.
- **Structured severe subagent returns** (`src/hooks/full-auto-delegation.ts`): free-form prose matches are now advisory-only and can never durably pause a run. A durable severe pause requires a schema-validated `SWARM_RETURN_STATUS: {json}` envelope claim plus corroboration from deterministic guardrail state (a recent scope/containment event naming a claimed path). Malformed envelopes never fabricate a violation. Delegation prompts carry a bounded instruction teaching the envelope.
- **#1964 closed**: all five runtime `AbortSignal.timeout()` sites (micro-reflector, two knowledge-curator calls, skill-generator, external-skill-discover) migrated to the shared `src/utils/abort-deadline.ts` (manual controller + always-cleared timer; `admission.ts`'s local helper now delegates to it). A source + built-bundle scan test enforces zero runtime `AbortSignal.timeout(` remains.

## Notes for #1896

Row 3 of the #1896 closure matrix (quota/rate-limit failure causes the actual role dispatch to use a configured fallback) is now covered end-to-end by the per-session override store and the request-level tests in `tests/unit/agents/model-override.test.ts`. Rows 1, 2, and 4 remain open follow-ups; #1896 stays open.
